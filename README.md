GitLab Cloud Ingestion Connector is a production-grade cloud data connector built in Go (1.22) that incrementally ingests activity and audit streams from the GitLab REST API (free tier compatible). It features Redis monotonic watermark checkpointing for deduplication, an embedded Web UI Dashboard for real-time telemetry and pre-flight connection diagnostics, and automated Kubernetes and ArgoCD GitOps deployments.
